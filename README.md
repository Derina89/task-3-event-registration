# Task 3 — Event Registration Web Pages

## Project Overview
This project is part of the SAN Web Technology Full-Stack Development Internship. It is an Event Registration Web Application that allows users to view event details and register for an event.

The application uses HTML, CSS, JavaScript, Node.js, and Express.js. Registration details are validated and stored in a JSON file without using a database.

## Features
- Event Details page to display event information.
- Registration page with a form to collect participant details.
- Client-side form validation using JavaScript.
- Server-side validation using Express.js.
- Confirmation page after successful registration.
- Registration details stored in a JSON file.
- Registrations page to view submitted records.
- Registration records remain available after refreshing the page.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON for data storage

## Project Structure
The project includes the following main components:

- Event Details page
- Registration page
- Confirmation page
- Registrations page
- Express.js server

## How to Run the Project

### Prerequisites
- Node.js installed on your system.
- npm installed with Node.js.

### Steps
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install the required dependencies:

   ```bash
   npm install
   ```

4. Start the server using the start command configured in `package.json`.
5. Open the local URL configured by the application in your browser.

## How It Works
1. Users view the event details.
2. Users enter their information in the registration form.
3. The form validates the entered details on the client side.
4. The Express.js server validates the submitted information.
5. Valid registration details are stored in a JSON file.
6. Users see a confirmation page after successful registration.
7. The registrations page displays the stored registration records.
